# Audio Datasets

This directory contains information about audio and speech datasets.

## Categories

- **Speech Recognition**: Transcribed speech data
- **Speaker Recognition**: Speaker identification and verification
- **Music**: Music analysis and generation
- **Audio Classification**: General audio event classification
- **Text-to-Speech**: Speech synthesis datasets
- **Emotion Recognition**: Emotion in speech

## Popular Datasets
