# Text Datasets

This directory contains information about text-based datasets for various NLP and LLM tasks.

## Categories

- **Language Models**: Large-scale text corpora for training language models
- **Question Answering**: QA pairs and reading comprehension datasets
- **Instruction Following**: Instruction-response pairs for fine-tuning
- **Code**: Source code datasets for code generation and understanding
- **Dialogue**: Conversational datasets
- **Classification**: Text classification tasks
- **Translation**: Parallel text for machine translation
- **Summarization**: Document-summary pairs
