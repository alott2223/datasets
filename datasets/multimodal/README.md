# Multimodal Datasets

This directory contains information about datasets combining multiple modalities (text, image, audio, video).

## Categories

- **Image-Text**: Image captioning, VQA, visual reasoning
- **Video-Text**: Video captioning, video QA
- **Audio-Visual**: Combined audio and visual data
- **Vision-Language**: General vision-language tasks

## Popular Datasets

See [CATALOG.md](../../CATALOG.md) for a comprehensive list of multimodal datasets.
