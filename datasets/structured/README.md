# Structured Data Datasets

This directory contains information about structured data including tables, knowledge graphs, and databases.

## Categories

- **Knowledge Graphs**: Semantic knowledge representations
- **Tables**: Structured tabular data
- **Benchmarks**: Evaluation datasets
- **Scientific Data**: Domain-specific structured datasets
- **Relational Data**: Database dumps and relational datasets
