# Image Datasets

This directory contains information about image datasets for computer vision tasks.

## Categories

- **Classification**: Image classification datasets
- **Object Detection**: Datasets with bounding boxes
- **Segmentation**: Semantic and instance segmentation
- **Face Recognition**: Face and identity datasets
- **Medical Imaging**: Medical and healthcare images
- **Satellite Imagery**: Remote sensing data
- **Generation**: Datasets for generative models
